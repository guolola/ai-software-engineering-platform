## 概述

SEO 配置由页面标题与描述、规范链接、结构化数据、站点地图、robots 规则和生产预渲染共同组成。最终地址以 `PUBLIC_WEB_BASE_URL` 为准。

## 当前设计或配置

- 首页与公开内容页提供稳定的标题、摘要和规范 URL。
- 构建过程生成或校验站点地图、robots 与公开页面的静态输出。
- 登录后业务页面不作为搜索落地页，公开教程用于承载可索引的使用说明。
- 生产构建要求明确站点根地址，避免生成本地或错误域名链接。

## 操作与维护

1. 新增公开路由时补齐标题、摘要、规范链接和必要的结构化数据。
2. 路由改名时同步站点地图、内部链接和重定向策略。
3. 更新品牌或域名时全仓检查旧名称与旧地址。
4. 发布后向搜索平台提交新的站点地图，并观察抓取错误。

## 验证

```bash
npm run build:web:production
```

检查生产 HTML 中的标题、描述、规范链接和结构化数据，并确认 `robots.txt`、站点地图、首页与 `/tutorial` 返回成功且没有本地地址。
