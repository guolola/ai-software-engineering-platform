# Coding Agent 接入与授权

## 适用场景

平台保存需求、分析、设计与测试依据。通过 MCP 连接你使用的 Coding Agent，由外部工具实现代码、运行程序和验证结果。

## 入口位置

项目列表左侧的 [Coding Agent](/projects/connections)。旧账号连接页自动跳转到此页；客户端发起的 OAuth 授权页面仍可使用。

## 前置条件

登录平台，创建或加入至少一个项目；平台已开放 MCP 服务。保存需要交给 Agent 的项目内容。

## 操作步骤

1. 选择客户端，查看 CLI 命令、配置示例与官方文档。
2. 按终端命令或配置说明添加 MCP 地址；仅支持桌面端接入的客户端按官方文档操作。
3. 选择“浏览器授权”或“个人令牌”。浏览器授权从客户端发起，登录平台并勾选允许读取的项目。个人令牌填写连接名称即可创建，可读取账号当前有权限的全部项目，包括之后创建或加入的项目；令牌只展示一次，请保存在客户端凭据设置或环境变量中。
4. 展开案例列表，把“某某自己项目”替换为你的项目名称，再将提示词交给 Agent。让它确认对应项目、检查当前仓库后读取依据，完成实现并报告测试结果。
5. 查看连接记录和最近成功调用时间；不再使用时撤销连接。

## 结果与产物

| 状态 | 含义 |
| --- | --- |
| 未连接 | 没有连接记录 |
| 待验证 | 授权有效，尚未发生成功调用 |
| 连接成功 | 授权有效，后端记录了成功调用；不表示 Agent 持续在线 |
| 已过期 / 已撤销 | 需要重新接入或授权 |
| 服务未启用 | 平台尚未开放 MCP |
| 状态未更新 | 读取失败，缓存不能代表当前状态，请刷新重试 |

页面可见时每 10 秒读取状态，返回页面或手动刷新时立即读取，隐藏或离开后停止轮询。平台不接收外部执行进度和代码成果。

## 映射关系

| 平台内容 | 外部使用 |
| --- | --- |
| 需求规则与用例 | 功能、约束与验收标准 |
| 分析与设计模型 | 结构、业务流程与实现依据 |
| 已保存测试用例 | 运行与验证依据 |
| MCP 项目授权 | 跨项目只读访问范围 |

需求分析中的“原型界面关系图”及 PlantUML 源码继续保留，它们属于模型产物。

## 常见问题

- 页面提供文字与配置示例；客户端入口随版本变化，以对应官方文档为准。
- 某客户端没有 CLI 指引：查看该客户端官方文档，不能将另一产品的配置套用过来。
- 授权后仍显示待验证：让 Agent 发起一次真实的项目读取，成功后状态会更新。
- 复制失败：手动选择文本复制；不要把令牌提交到仓库。
- 权限变化：个人令牌会遵循账号最新项目权限；浏览器授权需要确认所选项目仍可访问。
- 旧代码快照无法恢复：平台内代码生成、编辑及预览已移除；已有文档和其他阶段产物继续保留。
