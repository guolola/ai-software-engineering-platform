# 认识项目工作台

## 适用场景

第一次进入项目，想快速找到功能、打开模型详情，或在多个页面之间切换。

## 入口位置

从[项目首页](/projects)打开任意项目。小屏下点击 **打开项目导航** 展开菜单。

## 前置条件

当前账号拥有项目访问权限。生成、保存和管理操作还取决于成员角色。

## 操作步骤

### 1. 按阶段进入页面

左侧 **项目导航** 包含 **系统需求、可行性分析、需求模型、设计模型、测试、说明书**。点击阶段名称进入该阶段首页。

下图是当前工作台：左侧按阶段展开模型，中间查看内容，顶部提供任务与项目操作。

![当前工作台：阶段导航、标签页和模型内容区](/help/images/docs-workspace-shell.png)

### 2. 展开模型查看细节

生成模型后，展开对应阶段和模型，打开 **跟踪矩阵**、**元素** 或 **关系**。例如展开 **需求模型 → 用例模型**，查看学生、管理员和预约用例。

### 3. 用标签页保留查看位置

打开的内容显示为标签页。再次打开同一内容会复用已有标签。标签页菜单可以 **关闭其他标签** 或 **关闭同阶段标签**。

### 4. 查看进度与项目操作

顶部 **生成任务** 查看当前任务；**运行历史** 查看过去结果；**链路图** 查看跨阶段来源。成员、项目设置和文档中心的操作见[项目管理入口](project-drawers.md)。

## 结果与产物

| 区域 | 用法 |
| --- | --- |
| 左侧项目导航 | 选择阶段、展开模型和元素 |
| 中间内容区 | 输入需求、生成内容、查看图表 |
| 标签页 | 在多个已打开内容之间切换 |
| 顶部操作 | 查看任务、历史、链路和项目管理 |

## 映射关系

阶段首页负责生成和检查状态；模型子菜单负责查看具体结果。**需更新** 表示上游内容改变，**生成失败** 表示本次生成出现错误，两种状态应分别处理。

> [!NOTE]
> 要实现代码，请返回项目列表的 **编程助手** 连接外部工具。接入方法见[Coding Agent 接入与授权](coding-agent.md)。

## 常见问题

**侧栏没有某张图？** 先确认该图已经生成并保存。查看阶段首页的状态卡片和生成任务。

**小屏找不到菜单？** 点击 **打开项目导航**；项目快捷操作可从 **打开项目操作** 进入。

**标签页太多？** 打开标签页操作菜单，保留当前内容并关闭其他标签。
