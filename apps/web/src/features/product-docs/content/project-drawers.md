# 项目设置与成员管理

## 适用场景

需要修改项目资料、邀请成员，或从工作台查看任务、历史和已生成文档。

## 入口位置

项目工作台顶部的快捷按钮；小屏下使用 **打开项目操作** 菜单。

## 前置条件

当前账号是项目成员。具体管理操作由角色控制；按钮旁会说明权限不足的原因。

## 操作步骤

### 修改项目资料

打开 **项目设置**，修改名称、描述、背景、可见性、课程或团队归属，以及数据留存策略。检查内容后保存。

![项目设置：在抽屉中查看并修改项目资料](/help/images/docs-project-settings.png)

### 邀请与管理成员

打开 **成员**，输入被邀请者邮箱并选择合适角色。已有邀请可查看状态，并按需要重发或撤销；成员角色可在权限允许时调整。

![成员管理：查看角色与加入状态，或通过邀请入口添加协作者](/help/images/docs-project-members.png)

### 查找任务和文档

- **生成任务**：查看正在排队或运行的内容、失败项和执行详情。
- **运行历史**：查看历史记录；可执行的恢复、重试等操作以该记录提供的按钮为准。
- **文档中心**：查看说明书版本、下载和在线编辑状态。

> [!WARNING]
> **项目设置** 中的归档、转移与删除会影响项目状态或归属。执行前先阅读确认提示，尤其要区分归档与删除。

## 结果与产物

保存后的项目资料用于辨认和管理项目；成员与邀请记录决定协作者的访问权限；文档中心保留生成的交付文件。

## 映射关系

这些入口都服务于当前项目。账号级模型配置位于 **账号设置 → 全局设置**，详见[账号与默认模型](account-global-settings.md)。

## 常见问题

**设置或成员操作不可用？** 检查成员角色与页面权限提示，再联系项目负责人。

**成员收不到邀请？** 核对邮箱和邀请状态，必要时重发。

**运行历史为空？** 先确认项目中是否已有生成记录。任务进度与历史操作见[生成任务与历史](generation-tasks-history.md)。
