# 生成权益与账单

## 适用场景

查看剩余生成次数、购买次数包、继续未完成订单，或核对支付结果。

## 入口位置

登录后进入[账户账单](/account/billing)。生成因次数不足被拦截时，也可从页面提示进入。

## 前置条件

使用当前登录账号核对余额和订单。购买前查看页面展示的次数、有效期和价格。

![账户账单：检查权益余额和有效期，再查看套餐与订单；图中数值仅为演示](/help/images/docs-billing.png)

## 操作步骤

1. 查看可用次数和有效期，确认是否需要购买。
2. 选择在售次数包，创建订单。
3. 按支付页面完成付款，再返回平台。
4. 刷新订单状态与权益余额，确认购买结果。
5. 已有有效的待支付订单时，点击 **继续支付** 使用原订单。

> [!TIP]
> 支付后暂未更新时，先刷新原订单。确认订单状态前不要重复购买同一份次数包。

## 结果与产物

得到可用生成次数、订单状态，以及赠送、购买、消费或调整形成的权益流水。

## 映射关系

支付成功的订单对应权益变动；平台托管模型的生成资格由可用权益与页面规则决定。**个人供应商不消耗平台权益次数**，其调用费用由外部供应商结算。

## 常见问题

**支付成功但次数没变？** 刷新订单，确认支付和查看时使用同一账号。仍未更新时保留订单号，联系管理员核对。

**待支付订单要重新创建吗？** 有效订单优先使用 **继续支付**；已关闭或失效的订单需要重新创建。

**平台次数等于供应商余额吗？** 两者分别记录，不能互相替代。

**赠送次数与有效期是多少？** 以当前账户账单显示的发放记录、余额和有效期为准。
