# 生成权益、购买与订单处理

## 适用场景

当你需要查看剩余生成次数、购买次数包、继续未完成支付或核对订单状态时，使用本页说明。

## 入口位置

登录后从顶部账号入口打开权益或订单页面。生成操作因权益不足被拦截时，也可以从提示进入购买流程。

## 前置条件

- 已登录平台账号。
- 购买前确认当前剩余次数和套餐内容。
- 支付完成后返回同一账号查看结果。

## 操作步骤

1. 打开权益页面，核对可用次数和有效期。
2. 选择在售次数包并创建订单。
3. 按支付页面完成付款，不要重复创建相同订单。
4. 返回平台刷新订单状态和权益余额。
5. 对仍处于待支付状态的订单，使用“继续支付”恢复原订单。

平台赠送、购买和消耗记录以权益流水为准。使用个人 Provider 时，模型费用由对应供应商结算，平台是否扣减生成次数以页面当前规则和服务端校验为准。

## 结果与产物

- 当前可用生成次数与有效期
- 购买订单及其待支付、已支付、已关闭等状态
- 赠送、购买、消费或调整形成的权益流水

## 映射关系

订单支付成功后映射到权益流水；权益流水决定受限生成动作是否可以开始。Provider 配置与外部模型账单是另一条链路，不等同于平台订单。

## 常见问题

**支付完成但次数没有更新怎么办？**

先刷新订单并确认支付账号一致。若订单仍未更新，保留订单号并联系管理员核对支付回调，避免重复付款。

**待支付订单是否必须重新创建？**

不需要。订单仍有效时优先使用“继续支付”；已关闭或失效后再创建新订单。

**平台次数是否等于模型供应商余额？**

不等于。平台权益和外部供应商账户分别记录，实际模型费用以供应商账单为准。
