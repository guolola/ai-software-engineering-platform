# 配置 Provider

## 适用场景

当你需要使用自己的 OpenAI 兼容模型服务、发现可用模型、测试连接或调整默认模型时，使用本页说明。

## 入口位置

从顶部账号入口打开“账号设置”，进入全局模型配置或 Provider 管理区域。项目工作台会读取这里保存的可用配置。

## 前置条件

- 准备供应商提供的 HTTPS Base URL 和 API Key。
- 确认供应商支持 OpenAI 兼容的模型发现与聊天接口。
- 了解使用个人 Provider 产生的模型费用由供应商账户结算。

## 操作步骤

1. 新增个人 Provider，填写便于识别的名称。
2. 填写供应商 Base URL 和 API Key。
3. 执行连接测试并获取当前可用模型列表。
4. 选择默认模型，保存配置。
5. 回到项目工作台，在生成前确认实际选中的 Provider 与模型。

Base URL 可以填写供应商根地址或兼容端点，平台会按当前合同规范化请求路径。不要在名称、备注或截图中泄露 API Key。

## 结果与产物

- 加密保存的个人 Provider 配置
- 供应商当前返回的模型列表
- 连接测试状态和默认模型选择

## 映射关系

账号级 Provider 为项目生成提供可选模型。具体生成任务会记录实际使用的 Provider、模型和运行状态；平台权益与供应商账单分别管理。

## 常见问题

**为什么获取不到模型？**

检查 Base URL、API Key、供应商接口兼容性和账户状态，再重新测试。模型清单由供应商实时返回，不保证与其他账号相同。

**应该填写完整的聊天接口吗？**

优先按供应商文档填写 Base URL。平台支持常见根地址和兼容端点形式，并会避免重复拼接路径。

**个人 Provider 会暴露密钥吗？**

密钥应由服务端加密保存，界面和日志不会回显明文。若怀疑泄露，请立即在供应商后台撤销并更换。
